# Glossary

Common rail, software, hardware, and certification terms used across
OpenSourceRail.

| Term | Meaning |
|---|---|
| ATO | Automatic Train Operation: controls traction/braking within the movement authority. |
| ATP | Automatic Train Protection: safety layer that trips or limits the train when authority, speed, or position is unsafe. |
| AW0 / AW2 / AW3 | Passenger loading cases: empty, normal loaded, and crush loaded. |
| BOM | Bill of materials. The repo separates planning BOMs, procurement BOMs, and board BOMs. |
| COTS | Common off-the-shelf component. In OSR docs this means sourceable modules with supplier evidence, not hand-designed internals. |
| EN 14752 | European standard for bodyside doors on railway vehicles. |
| EN 15085 | Welding standard for railway vehicles and components. |
| EN 15227 | Crashworthiness standard for railway vehicle bodies. |
| EN 50126 / 50128 / 50129 | RAMS, safety software, and safety-related electronic-system standards for rail. |
| EN 62267 | Automated urban guided transport safety standard; primary GoA 4 reference for OSR certification docs. |
| FEA | Finite element analysis, used for structural, fatigue, and crashworthiness evidence. |
| GoA 4 | Grade of Automation 4: unattended train operation with no driver in the train. |
| GSN | Goal Structuring Notation, used for the machine-checkable safety-case structure. |
| HVIL | High-voltage interlock loop, proving HV connectors/covers are closed before energisation. |
| Kani | Rust model-checking tool used for bounded safety-property proofs. |
| MA | Movement authority: the safe track extent a train is allowed to occupy. |
| MBOM | Manufacturing bill of materials, more detailed than the repository's planning/procurement BOMs. |
| NDT | Non-destructive testing such as visual, magnetic-particle, ultrasonic, or radiographic inspection. |
| OCC | Operations control centre. |
| PRM | Persons with reduced mobility. |
| PSD | Platform screen door. |
| SIL | Safety Integrity Level. OSR uses SIL-4 for train protection and safety-critical supervision. |
| TCN | Train communication network. |
| T-ECU/S | Train electronic control unit, safety kernel. |
| T-ECU/A | Train electronic control unit, application layer. |
| T-OBS | Train obstacle-detection host. |
| W-SBC / S-SBC | Wayside and station single-board-computer host classes. |
