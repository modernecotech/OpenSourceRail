# Provisional finite-group launch optimisation

108 equal-service winding/group/voltage candidates; 33 satisfy the implemented analytical current/voltage/heat screens.

Each result binds the exact component-accounted vehicle configuration and motion profile. Groups contain whole2.5m cassettes; the loss-minimizing finite-group current allocation is rejected when current or voltage limits cannot produce the requested trajectory. Booster stock and heat remain separately counted.

Installed lifetime cost includes finished copper, every converter and sensor/protection group, stator hardware, cooling, idle power, maintenance and converter renewal. Assumed train passages and regeneration reuse are explicit finance sensitivities, not route or grid acceptance.
