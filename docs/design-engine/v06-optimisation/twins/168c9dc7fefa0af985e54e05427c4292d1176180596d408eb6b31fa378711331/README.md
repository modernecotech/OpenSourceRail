# Wheel-rail known-stock research twin

OpenSourceRail pursues simple, locally repairable station-powered transport. This package connects one wheel-rail candidate to known-stock geometry and draft delivery records.

Candidate `168c9dc7fefa0af985e54e05427c4292d1176180596d408eb6b31fa378711331`; requirements `V06-WHEEL-LIM-COMFORT-1`. 2860 known geometric occurrences, representing one car, a separate station module and selected guidebeam stock. Vehicle and station coordinates are separate frames, not an installed assembly clearance demonstration.
