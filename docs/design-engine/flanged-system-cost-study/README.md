# Flanged-span whole-railway Class C scenarios

Three 20 m steel-girder and concrete-deck research configurations retain the same selected six-car vehicle, provisional mass cases and synthetic 6 km two-track service. Each is bound to the pinned topology baseline and original flanged-span study. These are scenario estimates, not a qualified railway or site budget.

Whole-life deltas and rankings against the canonical reference remain held: its separately modelled coating and bearing renewal events are not matched. Routine maintenance is assumed to exclude explicit capital renewals; actual overlap is unverified. Installed-cost differences retain an unchanged foundation/site price proxy and are conditional.

Factory routes use bounded reserve fabrication, QA, waste and declared two-shift production and construction; operations use 16/18/24-hour cases. Productive crane hours are converted to paid shifts using the declared utilization. Site capacity, pier and footing self-weight, crane capacity at radius, transport permits, structural performance, joint behavior, magnetic gaps, manufacturing and independent approval remain open.

Original requests, responses, logs, failure dispositions, source and runtime epochs are retained. Verification replays current-source analytical quantities and costs with an explicitly reported verifier runtime; it does not rerun a native solver or establish physical acceptance.
