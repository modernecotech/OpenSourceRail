# OpenSourceRail v0.5.1

The v0.5 series makes ferrite PM-biased maglev the primary mechanical, civil,
software and city-planning architecture. This release adds adaptive system
research and publishes a current, reproducible digital evidence set.

The existing `v0.5.0` tag is preserved. `v0.5.1` identifies this tested release.

- Generate section/span, vehicle mass-allocation and actual Rust-controller
  variants from preceding numerical results. Retain exact identities, ancestry,
  traces, Pareto observations, preference weights and bounded termination.
- Confirm shortlisted revisions with separate load/disturbance scenarios.
  Failed confirmation removes recommendation eligibility; analytical history
  remains available. Interrupted or changed-source work resumes from exact-source
  receipts or starts another epoch.
- Publish current FreeCAD/STEP studies, exported images, five assembly visibility
  videos, the local review UI, a reader PDF and 266 maglev city-planning packages.
- Clean current entrypoints, README files and city generators of obsolete vehicle
  assumptions; describe coupling allowances consistently with the configuration.
- Keep configured suppliers and origins, physical evidence and full installed
  costs explicit rather than converting planning targets into achieved savings.

This is a software and digital-study release. Accepted engineering items remain
zero. The adaptive results use ideal magnetic-force hypotheses, assumed mass and
inertia allocations, a stationary single rigid car and a flexible vertical beam.
They do not demonstrate a complete manufactured train, global optimum, whole-train
stability, real magnetic efficiency, qualified civil strength or hardware timing.
The recommendation does not automatically change the reference configuration or
city costs. Assembly videos show final-position visibility, not motion/collision
or erection simulation. Walkway removal and unattended chute evacuation remain
unapproved. All manufacturing and physical release flags remain false.

Reproduce with `./osr build`, `./osr test` and `./osr readiness`. Run the adaptive
campaign explicitly with `./osr design iterate`. The installed local timer checks
for changed inputs every 15 minutes; unchanged campaigns idle after verification.
GitHub Actions remain disabled under the repository's local-processing policy.
