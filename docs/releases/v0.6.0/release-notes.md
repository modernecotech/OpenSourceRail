# Proposed v0.6.0 release notes

**Status: draft for a frozen release candidate; no public release is authorized.**

The existing annotated `v0.6.0` tag points to an earlier development baseline
(commit `61080cafc6998e587772810707dc552524df5306`); no GitHub Release is
attached. This draft does not move or replace that tag. The final release name
must be resolved separately after the software gates and independent review.

## Scope

v0.6 packages the OpenSourceRail planning, engineering-research and delivery
software. It keeps the development reference as six comfort cars on passive
steel-wheel bogies, conventional rails and concrete support. Alternative
propulsion, energy recovery and vehicle configurations remain distinct
research candidates.

The release focuses on a reproducible Samawah Workbench journey, source-pinned
Baghdad and candidate examples, transparent service/cost outputs, delivery
drafts, source identities and resource admission. It does not require a new
266-city calculation, broad design campaign or native solver sweep.

## Included

- City planning and editable outline proposals.
- Candidate-bound software calculations, cost scopes and delivery drafts.
- Workbench status, evidence links and reproducible exports.
- Rust control and protection research with explicit simulation limits.
- Optional ERPNext/Frappe HR and FUXA/gateway integration examples.
- Historical evidence and current engineering holds.

## Not included as accepted railway capabilities

- A manufactured or physically qualified train or guideway.
- Approved propulsion, braking, vehicle installation or safety case.
- Manufacturing, construction, movement or operating authority.
- Surveyed city corridors, vendor-qualified quotations or commissioned ERP/
  SCADA deployments.

See [feature maturity](feature-maturity.md) and [known limitations](known-limitations.md).
