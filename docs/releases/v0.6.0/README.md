# OpenSourceRail v0.6.0 software release package

**Release state: withheld pending the six software gates and an authenticated independent review.**

This package is prepared for a software and engineering-research release. It
does not declare the railway physically accepted, ready to manufacture, cleared
to move, or authorized to operate. The committed dashboard remains pending in
the [software-release ledger](../../design-engine/v06-software-release/README.md).
