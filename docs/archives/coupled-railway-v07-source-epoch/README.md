# Retained v0.7 coupled research source epoch

The [coupled railway research packet](../../design-engine/coupled-railway-v07/README.md)
is kept at its original source epoch, commit
`e4e73bfdda720c608816aa76a78148855ab8443b`. Its manifest binds 49
payload files and 66 original source files. `sources.tar.gz` contains those
source bytes; the packet and archive are checked by
`engineering.station_rail.retained_v07_coupled.verify` during selected
publication.

This preserves the completed experiment without rerunning 112 bundles for a
package-version change. It does not admit its results under current evaluators
or qualify a physical railway. New geometry, loads or methods require a new
evaluation and source identity.
