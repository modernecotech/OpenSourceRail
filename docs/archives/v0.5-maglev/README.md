# Historical v0.5 maglev design

The permanent-magnet suspension development design is preserved at Git revision `92e1385e03dcd5c6f76a5b0a9dd5ba348f50d164`. Its exact source, reader, current packets and city outputs remain in Git; this compact index avoids duplicating large generated datasets. The [v0.6 default](../../design-engine/current/README.md) uses passive wheel bogies and station propulsion. Magnetic suspension findings, quantities and costs do not describe that vehicle.

Use `./osr legacy verify` to check both retained archives. To inspect this snapshot in a writable but isolated checkout, run `./osr legacy checkout v0.5-maglev --path /tmp/opensourcerail-v05-maglev`. Its `./osr` front door routes to the v0.6 entry point, so use the formal `v0.5.1` tag to reproduce the old `capabilities`, `catalogue`, `city`, `sim` and `design iterate` command contracts: `./osr legacy checkout v0.5.1 --path /tmp/opensourcerail-v051`. The checkout does not copy the ignored `.venv`; historical numerical commands need a compatible Python environment with `engineering/ferrite_maglev/requirements.txt` installed. Run historical tools and keep their generated outputs and explicit `--output` paths inside that worktree. Remove it when finished with `git worktree remove /tmp/opensourcerail-v05-maglev`. Historical writers must not overwrite current outputs or feed magnetic quantities into v0.6.
