# Historical v0.5 maglev design

The permanent-magnet suspension development design is preserved at Git revision `92e1385e03dcd5c6f76a5b0a9dd5ba348f50d164`. Its exact source, reader, current packets and city outputs remain in Git; this compact index avoids duplicating large generated datasets. The [v0.6 default](../../design-engine/current/README.md) uses passive wheel bogies and station propulsion. Magnetic suspension findings, quantities and costs do not describe that vehicle.

Use `./osr legacy verify` to check both retained archives. To restore its old commands in a writable but isolated checkout, run `./osr legacy checkout v0.5-maglev --path /tmp/opensourcerail-v05-maglev`; use `v0.5.1` to reproduce the formal release tag. Run historical tools and keep their generated outputs inside that worktree. Remove it when finished with `git worktree remove /tmp/opensourcerail-v05-maglev`. Historical writers must not overwrite current outputs or feed magnetic quantities into v0.6.
