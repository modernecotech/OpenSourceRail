# Viaduct First-Article Test Plan

The first production mould, first U20/U25 unit, first cap shell, first erected
bay, and first completed track/egress bay are hold points. Production may not
free-run until the responsible engineer and independent checker accept the
applicable evidence.

| Hold point | Minimum evidence |
|---|---|
| Mould and casting bed | Survey, stop-end settings, tendon/rebar/inserts, release agent, concrete process, calibration |
| First girder | Materials, cube/cylinder strength, maturity, prestress force/elongation, transfer sequence, dimensions, camber, cover, NDT, drainage test |
| Trial lift and transport | Certified lifting design, load test where required, strain/deflection observations, temporary bracing, transporter trial and route clearance |
| Cap/column connection | Reinforcement and connection record, geometry, bearing-seat survey, grout/concrete acceptance, jacking interface |
| First erected bay | Bearing identity/orientation, two-row survey, reactions/level, girder geometry, gaps, stability, diaphragm/end-zone inspection |
| Track and egress | Waterproofing, local plinth geometry, fastener proof/torque, drainage flow, 1.0 m clear walkway, 1.4 m containment datum, gap covers, earthing |
| Structural acceptance | Correlated analysis; static/dynamic proof test if required by the design basis; residual deflection/cracking criteria; independent-check closure |

Nonconformities require disposition, repaired-item acceptance, root-cause
review, and demonstrated recurrence controls before the production hold point
is released.
