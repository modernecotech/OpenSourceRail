# Buying a railway using an open reference

Amanat Baghdad can use OpenSourceRail to write a specification, estimate quantities and negotiate the right to build and repair locally, whether an Iraqi consortium, an international supplier or a combination delivers the railway. The working estimate is a negotiating reference. A credible fallback to a vendor offer requires priced local packages, a capable integrator, financed tooling and an acceptance programme.

## Issue the same scope to every bidder

Request three returns for one network at a time. Invite a turnkey offer, a vendor-led offer with specified transfers of production and repair, and a locally integrated offer using open interfaces. Allow vendors to quote all three. Provide the same train capacity, accessibility, hourly service, route assumptions, construction dates, excavation exclusions, summer duty, spares and 30-year maintenance horizon. Require a priced departures register against the open bill. Require each supplier to identify interface responsibility through commissioning and warranty. The sponsor carries any scope it retains in a split award.

| Return schedule | What the bidder supplies | How the city compares it |
|---|---|---|
| Delivered and through-life price | Quantities, unit and recurring prices, freight, tax, currency, price date, schedule, exclusions, replacements and software fees | Reconcile the same fourteen capital scopes. Add buyer integration, retained risk, tooling and renewals once. Discount resource costs at the same date and real rate. |
| Financing | Cash price and financed price, draw dates, denomination, margin, premium, grace, fees, security, guarantees and refinancing terms | Compare annual buyer cash, peak budget draw and currency exposure separately from resource cost. Request an untied cash offer alongside tied export credit. |
| Production in Iraq | By lot and production year, ex-tax contract value, imported materials and subassemblies (including imports through local agents), domestic materials, local labour, local subcontract value and untraced inputs | Report Iraqi contract award and verified Iraqi value added separately. Require tier-level origin and invoices, eliminate intercompany/subcontract duplication, reconcile all values to the package price and show unverified value explicitly. |
| Repair and design rights | Part numbers, interface drawings and revision history, editable design files, test fixtures, diagnostic access, software build and licence terms, warranty limits, spare lead times and substitution rights | Price local overhaul, replacement and second sourcing. Have an Iraqi team reproduce the build or complete a witnessed repair using the delivered files and tools. |
| Transfer milestones | First article, coached assembly, independently built repeat article, local repair, training hours and signed inspection evidence | Tie acceptance and agreed retention to each demonstrated capability. Record remedies, cure periods and ownership of tooling before signing. |

Use the same ex-tax, ex-contingency, ex-financing denominator for all localisation comparisons. For a package priced at 100 units with 35 imported, 10 untraced and 55 documented domestic value, report **55% verified** and **10% untraced**, even if an Iraqi prime receives the entire contract. Aggregate by value across lots. Report skills separately in qualified staff, shop hours, independently accepted articles and turnaround time. A local address alone establishes none of these measures.

## Negotiate the price and the capability together

1. Publish the service specification, cost basis and evaluation method to all bidders. Make safety, accessibility and demonstrable delivery capability conditions for progression. Have the sponsor approve procurement rules and applicable lender conditions before issuing weighted criteria.
2. Obtain confidential, itemised first-round offers and independent local quotations. Keep bidder-proprietary details confidential. For each package compare cost per delivered unit, accessible capacity, performance guarantee and verified domestic content. Identify missing scope and price uncertainty explicitly.
3. Ask each bidder for a revised offer on the same baseline and for incremental prices to move named work into Iraq. Ask, for example, for the unit price and defect warranty for locally machined bogie frames after first-article acceptance, or locally tested control cabinets with the same protection equipment. Record tooling cost, minimum order, schedule, rights and five-year spares price alongside each change.
4. Report the lowest evaluated whole-life cost at each achievable domestic value-added level. Show the incremental cost or saving per additional unit of verified domestic value. Retain a cheaper turnkey return and a higher-local-content return as distinct options where neither dominates. A shortlist requires compliant performance, a matched delivery boundary and a funded integration owner.
5. Compare first and final offers on identical scope, currency and date. Claim a negotiated saving only for the like-for-like difference. Track *contracted* local content at award and *realised* value from audited invoices, factory inspections and acceptance records. The buyer may award to another vendor while retaining the reference, interface records and documented negotiating history.

Rated criteria and life-cycle cost are established procurement tools. Actual criteria and weightings require procurement-authority approval for the chosen financing. [World Bank guidance on rated criteria](https://www.worldbank.org/en/about/rated-criteria)
