# Hollow cantilever bending execution

[Benchmark](benchmark.json) records actual beam and solid responses, the hollow section and mesh size. [Beam input](beam.inp), [beam output](beam.dat) and [beam solver log](beam.log) retain the B32R BOX run. [Solid input](solid.inp), [solid output](solid.dat) and [solid solver log](solid.log) retain the C3D10 run.

The source-bound [parent receipt](../verification.json) also checks refinement. Results are numerical research evidence with no physical/manufacturing release.
