# Executed hollow-section benchmarks

[Receipt](verification.json) binds two Gmsh/CalculiX executions and their source/input/output hashes. A clamped hollow cantilever receives the same 1 kN tip force in the B32R BOX and C3D10 solid reductions.

[Coarse](coarse/README.md) and [refined](refined/README.md) meshes compare bending response and mesh refinement. This establishes a numerical consistency screen for that load case; torsion, local contact, fatigue and physical correlation remain open.
