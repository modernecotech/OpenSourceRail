# OpenSourceRail engineering

The [ferrite-PM maglev engineering package](ferrite_maglev/README.md) owns the
current requirements, configuration, mechanical/civil studies, city compiler,
manufacturing quantities, process estimates and evidence workflow.

[Native CAD utilities](factory_examples/native.py) construct and reopen current
solid definitions. [Current regression tests](analysis/tests/) cover analytical
controls, evidence binding, offline Rust integration and publication behavior.

Design responsibilities and test coverage are provisional. No complete detailed
railway design, qualified manufacturing process or physical release is claimed.
