# Independent plate formulation verification

[Verification](verification.json) compares the rectangular MITC4 strip against an analytical cylindrical-bending solution and actual CalculiX S8R results. [Input](plate.inp), [output](plate.dat) and [solver log](plate.log) retain the native execution.

This homogeneous benchmark validates a numerical formulation within its recorded tolerance; it does not validate the composite's constitutive properties, clips or physical service performance.
