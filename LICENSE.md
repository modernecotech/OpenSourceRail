# OpenSourceRail Licensing

OpenSourceRail uses a path-based multi-license model. The complete
license texts are tracked in [`LICENSES/`](LICENSES/README.md).

| Material | Default license |
|---|---|
| Software source, tests, scripts, and formal-model source | [Apache License 2.0](LICENSES/Apache-2.0.txt) |
| Hardware designs, mechanical CAD source/output, fabrication definitions, and assembly drawings | [CERN Open Hardware Licence Version 2 — Strongly Reciprocal](LICENSES/CERN-OHL-S-2.0.txt) |
| Documentation and original diagrams/media | [Creative Commons Attribution-ShareAlike 4.0 International](LICENSES/CC-BY-SA-4.0.txt) |

More-specific notices in a file or directory override this default.
Third-party inputs and generated artifacts retain their applicable
upstream terms. In particular, OpenStreetMap-derived data must preserve
its required attribution and database-license notices.

See [`LICENSES/README.md`](LICENSES/README.md) for the path mapping and
contribution rule.
